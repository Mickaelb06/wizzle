# ADR-008 — Licence
**Statut** : Accepté
**Décision** : code propriétaire, tous droits réservés (`LICENSE`, placeholder à faire valider par un juriste avant toute diffusion). Dépendances open source autorisées sous licences compatibles ; vérification automatique par `cargo deny` (liste blanche : MIT, Apache-2.0, BSD, ISC, MPL-2.0 selon cas ; AGPL/GPL exclues sauf ADR).
**Conséquences** : l'ancien fichier Unlicense (domaine public) a été remplacé ; il n'avait pas été utilisé par du code.
